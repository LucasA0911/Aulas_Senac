# Diferença entre Numeros e Caracteres.
Se faz conta -> Números.
Se não faz conta -> Caracteres.

Exemplo:

Um CPF é um conjunto de números. Porém não fazemos contas com CPF.
Outro Exemplo. Para os Números o 0123 ou o 123,0 continuam sendo 123. Porém nos caracteres o 0 importa, o 0123 é um 0123 e um 123,0 é um 123,0

# Tipos de Bancos de dados
- Bancos de dados *relacionais* são os bancos estruturados como tabelas por exemplo.

- Bancos de dados *não relacionais* são Projetados para lidar com dados em grande escala, armazenam dados em vários formatos não relacionais, como documentos, graficos ou colunas. Porém não são bons para dados estruturados ou semi-estruturados. 
Mongo DB é um dos exemplos de linguagem de acesso.

- Bancos de dados *Orientado a Objetos* integra conceitos de programação orientada a objetos nos ambientes de banco de dados.

- Bancos de dados *hierárquico*, organiza os dados em uma estrutura em formato de árvores semelhante a um arquivos de pastas e subpastas

- Bancos de dados *de rede* utiliza um modelo semelhante a um grafo para permitir relações entre entidades. É uma estrutura não hierárquica.

- Bancos de dados *baseado em Nuvem* Basicamente são bancos de dados que estão hospedados em um sistema de computação em nuvem como AWS
