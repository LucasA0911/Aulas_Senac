## Funções de ativação:
- Função Sigmoid: Utilizada em problemas de classificação binária, mapeia valores reais para um intervalo entre 0 e 1. 

- Função Tanh: Centrada, ajuda a acelerar o aprendizado em alguns casos, mas pode ser menos eficaz em redes profundas. 

- Função ReLU (Rectified Linear Unit): Popular devido à sua eficiência em redes profundas, retorna 0 para valores negativos e o próprio valor para entradas não negativas.

## Multilayer perceptron
- Para normalizar os dados utilizamos o z-Score que é o seguinte calculo -> *valor - media do valor / pelo desvio padrão ou z=(x-u)/dp*
- É necessário realizar a normalização de dados antes de colocar nos input nodes.
- Quantidade de neuronios é importante pois quanto mais neuronios mais refinado será a rede neural, pois ela calculará mais vezes as entradas.
- Em uma rede neural os pesos são atualizados pela propria rede neural
- O target não é informado na entrada, pois queremos que a propria rede neural descubra qual é o target
- *Feed foward* é o calculo inicial para saber se a rede neural acertou o target
- *Back propagation* o processo de refazer os calculos caso ela não acerte o target
- Geralmente uma rede neural é treinada com 70% dos dados do DataSet e testada com os outros 30%
- Uma rede neural precisa ter no minimo 97% de acertividade
- Epoca é a quantidade de vezes que a rede neural tem que fazer o back propagation. Geralmente o pessoal utiliza 1000 epocas para treinar a rede neural
